# Portfolio – Christopher Tremblay

Site statique (HTML, CSS, JavaScript). Ouvrir `index.html` dans un navigateur.

## Ajouter sa photo
Déposer la photo dans `images/photo.jpg` (format portrait 4:5 conseillé).
Tant que le fichier n'existe pas, un emplacement avec les initiales s'affiche.

## Ajouter ou modifier un projet
1. Dans `index.html`, copier un bloc `<article class="project-card">` de la section Projets.
2. Changer `data-category` (`web`, `api` ou `jeu`) pour le filtre.
3. Déposer l'aperçu dans `images/projets/` (format 16:9) et mettre son nom dans `src`.
4. Remplacer les liens `href="#"` par l'adresse du site et du code (GitHub).
